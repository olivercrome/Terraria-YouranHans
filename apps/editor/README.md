# YouranEditor（apps/editor）

面向「泰拉瑞亚/悠然汉化」的**便携式安卓 JSON 汉化编辑器**（主单机工具）。

一手在手机上把 `Localization/*.json` 当"工作台"来维护：以**分支 + json 页 + 收藏定位**组织，
支持原位编辑 key、高亮大/对象逐层下钻、批量入库、保存快照历史。

---

## 功能一览（当前版本 v2.2）
- **分支 / 文件页**：本地草稿分支可直接工作（SAF 目录读取路径亦有支持），进入即列出该分支下 `.json`。
- **新建空分支 / 从原版模板展开**：可从内置 `original-zh-Hans.zip` 一键铺出模板 json。
- **原生 JSON 树编辑器**：
  - 对象/数组逐层下钻渲染，key/value 原位编辑；
  - 「新建 key」两种模式：**直接给值** / **对象壳（自动下钻续填）**；
  - 取色帮助、`[i:itemID]` 配对、行内 `/` 换行等小工具。
- **⭐ 收藏定位**：整文件 / 具体 key 都可收藏，按分支→文件→key 自动归类；删除分支会自动清空其孤儿收藏。
- **🔍 搜索下钻**：字符串命中直达该行（ListView.setSelection），不翻屏。
- **🕘 保存历史**：同 key 的差异（旧→新）自动留痕，红划线旧 / 绿新，按文件分组查看。
- **批量入库**：空分支一键「导入文件夹」（拷入目录下所有 json）或「自选 JSON」(多选) 批量拷入。
- **外观**：深/浅主题即时切换、可选莫奈/随机配色、历史内页卡片化等。
- **纯本地**：数据以本地文件为主；不依赖账号/网络（模板只在首次选择时读取 assets）。

## 📖 全面使用教程

### 第一步 · 首次启动 / 认识界面
1. 左上角 `≡` 打开**抽屉**，里面是你可编辑的**各分支**与「＋新建分支 / 新建一个干净模板」入口。
2. 中间主区随选中分支变化：
   - 刚安装只有主页大卡「🗂 新建模板分支」——点它 = **新建一个**带泰拉官方中文字段模板的新分支（不是进入别的目录）。
   - 出现分支后，在抽屉点分支 → 进入该分支的 **json 首页**。
3. 本应用**完全本地**：不联网、不需要账号；首次只要决定好你的 json 放哪即可。

### 第二步 · 把翻译 json 弄进某个分支
新分支通常是空的（首页会提醒“这个分支还没有文件”）。给它灌入 json 有 3 种途径：

- **A. 草稿（本地）直接放**
  在手机文件里进入应用私有草稿目录 `Android/data/com.youran.editor/files/…/<分支名>/` 放 json 即可（或用下面任一导入）。
- **B. 空页两个「导入」按钮（推荐快速体验）**
  首页为空时会显示：
  - **▁ 导入文件夹** → 选一个含 json 的目录，把它**顶层全部 *.json 拷进当前分支**（重复名自动跳过）。
  - **＋ 自选 JSON** → 可一次**多选**单个/多个 json 拷进来。
- **C.（进阶）SAF 目录挂载（说明）**
  代码已支持分支 SAF 授权与目录读取/写入，只是**当前构建在 main UI 上入口已收敛**（相关文案为预留）。绝大多数使用走到 A / B 即可：文件落在应用私有草稿目录由你直接管理，语义清晰。
  > 若你确实在真机装有很早版本并见过「绑定目录」，那份是为开发阶段暴露的；现行以草稿/导入为准。

> 想从「原版官中模板」重新铺一份（适合从零翻译去官汉自制）：用「新建模板分支」，会从应用内置模板包展开层级更完整的 json 骨架。

### 第三步 · 编辑 json 里的一层
- 点文件行进入**第一层**：每行是一个 key。典型分三类：
  - **叶子值**（就是一段文案/数字/布尔）→ 整行即一个可直接高亮编辑的条目。
  - **对象 / 数组**（值仍是 `{…}` / `[…]`）→ 点它**下钻**一层，里面再是一堆 key 的小列表，如此逐层到叶子。
- 编辑值/键：长按该行弹出动作（单个叶子的快捷新建/删除等），或将光标放进再输入。
- `/` 当作文本里不用转义即可换行（行内容自动读作换行），方便内置脚本维护大段语料。
- 部分行/工具菜单里出现小按钮时按需使用（例如取色协助、itemID 对照这类内建小工具在哪一层就按那一层的按钮触发），以帮助你填带颜色 tag 或 `[i:xxx]` 之类的值。

### 第四步 · 快速把大量文件定位/筛查到具体 key
- **🔍 搜索**：输入关键字，命中后直接 `跳到位` 并高亮对应行，不用一页页翻。
- **⭐ 收藏**（适合频繁校对某几处）——收藏粒度分两种，且都由对应行提供收藏/取消入口：
  。**整文件级**：在 json 文件列表里将该文件行收藏（行上会出现收藏标记）。
  。**具体 key 级**：下钻到包含该 key 的那一层，对该目标条目收藏/取消。
  。已收藏项按 **分支→文件→所在 layer/key** 自动归类，从收藏视图进入可直接打开/直达该条。
- 删除某分支后，它留在收藏里的孤儿会被自动清掉，不会污染“N 条”。

### 第五步 · 保存与“后悔药”
- 点右上保存（保存所编辑文件/整层）。保存只落**内存原文件**。
- **🕘 保存历史**：持续记录你对每个 key 的**旧→新**变化（红色删除线=旧，绿色=新）。想找回某个 key 上一版：进保存历史，按文件分组查看该 key 的演进；多次改同一 key 只留最终一版。
  > 历史目前为会话内内存（重开不回拨），看它定位“改前是啥”最有用，正式版重启即清。

### 第六步 · 别的常用
- **返回键**：分支/json 内按系统返回 = 回到主页（抽屉重选那些分支）；底部有引导卡。
- **深色/配色**：设置里即时切深/浅；主题可莫奈/随机/自定义，随时生效不重启。

### 第七步 · 构建 / 内测安装（开发者）
见下方「构建要求」；产出的 `app-debug.apk` 直接装真机即用。若愿做脚本化：命令内注意 Termux 请先
`export JAVA_HOME=$PREFIX/usr/lib/jvm/java-17-openjdk`。

### 小抄（导航速览）
```
抽屉选择分支 ──> 该分支文件列表 ──> 点对象层一路下钻 ──> 编辑叶子
收藏面板/搜索 ──> 直达目标 key     ──> 🕘历史看旧版变化
```

## 技术要点
- **纯 Java，Android 原生 + 少量 androidx**（appcompat/material 可选，去掉即可回纯 framework 单 dex 版）。
- minSdk 26 / target 34；编译 JDK 17。
- 主界面一个大 `MainActivity` + 一批小 helper 类（便于真机免联网单机）。

---

## 构建要求
- JDK 17（Termux：`pkg install openjdk-17`，`export JAVA_HOME=$PREFIX/usr/lib/jvm/java-17-openjdk`）
- Android SDK 34；构建时若需 aapt2 override：
  ```bash
  echo "android.aapt2FromMavenOverride=/usr/bin/aapt2" >> gradle.properties  # Termux 需要时
  ```
- 打包产物：
  ```bash
  cd apps/editor
  ./gradlew assembleDebug
  ls app/build/outputs/apk/debug/app-debug.apk
  ```

## 备注 / 关联
